## ポジションの関係

```
VPoT（CTO候補）── 全社・プロダクト横断の技術責任者
├── プロダクト横断で技術的に最適な方針を考える
├── マルチプロダクト横断のアーキ・インフラ・技術戦略
└── テックリードの上位

テックリード ── 担当プロダクトの技術責任者
├── アーキ・品質・セキュリティ
└── プロダクトチーム内の技術的意思決定

※ VPoTが全体方針を決め、TLが担当プロダクトで実現する
```
