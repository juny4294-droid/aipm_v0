# VPoT（CTO候補）採用

## 概要

**全社・プロダクト横断の技術責任者**として、技術方針・アーキテクチャ・インフラ・技術ガバナンスをリードする **VPoT（CTO候補）** の採用プロジェクト。

| 項目 | 内容 |
|------|------|
| ポジション名 | **VPoT（CTO候補）** |
| 役割の核 | 全社・プロダクト横断の技術方針（TLの上位） |
| 想定年収 | 1,000万〜1,500万円 |
| 勤務 | フルリモート可 |
| 開始日 | 2026-09-02 |
| フェーズ | 立ち上げ |
| 担当 | TBD |

> HERP上の職種名は「エンジニアVP候補」のまま。採用サイト・対外コミュニケーションでは **VPoT（CTO候補）** を使用。

## ポジションの位置づけ

```
今回採用するのは ──→  VPoT（CTO候補）
                      ├── 全社・プロダクト横断の技術責任者
                      ├── テックリードの上位（方針・戦略・全体アーキ）
                      └── マネジメント職ではない

テックリード ──────→  担当プロダクトの技術責任者

過去版VPoT ────────→  データ基盤・データマネジメント（役割は刷新）

将来の到達点 ──────→  CTO
```

## 過去版との違い（同名・別役割）

| | 過去版 VPoT | 今回 VPoT（CTO候補） |
|--|------------|---------------------|
| **責任の中心** | データ基盤・データマネジメント | **プロダクト全体の技術・アーキ・インフラ** |
| 主な業務像 | データ戦略、BI/DWH、データOps | 技術戦略、アーキ、インフラ、技術ガバナンス |
| 年収 | 810万円〜 | **1,000万〜1,500万円** |
