# 🔶 はじめに

> ### 「経営から、病院を変える。病院から、医療を変える。」
> 当社は、400床以上の大病院を中心に、「医療機関向けSaaSや伴走型コンサルティング」を提供するスタートアップです。

医療の質と持続可能性が問われ、医療機関の「変革」を支援するパートナーが求められている今、
メダップでは上記ビジョンを掲げ、医療×Vertical SaaSの領域で、病院の経営改善ひいては医療の持続可能性という社会課題に向き合っています。

当社が掲げるビジョンや事業の意義の詳細については、是非[メダップの目指す世界（note）](https://note.com/medup/n/n4deed8fd8c61)をご覧ください。

# 🔶 メダップのこと、事業のこと

> ### 医療×SaaSで、"病院経営"に真正面から向き合う。
> データ統合基盤を武器に、病院経営のDX・地域医療の持続可能化を支援しています。

当社は、情報技術を活用してサービスを多く立ち上げ、無理のない質の高いオペレーションを日本中の医療機関・医療従事者に広めることを目指しています。

これまで、病院経営の改善と地域医療の向上により貢献できる事業運営のため、積極的に資金調達を行ってきました。直近では、2024年3月にプレシリーズBで3.8億円を、2025年3月にはベンチャーデットにて1.3億円を調達し、累計約14億円の資金を確保して事業を拡大しています。

> ### 病院特化型AIワークフローで、業務改革をリードする
> 複雑だけどルール化された業務が多い病院で、**AIワークフローを活用した業務改革**——それが、いまメダップが重点的に進める事業方針です。

> ### コンパウンドSaaS × 伴走型コンサル
> foro CRM 等のSaaSとCS/PSによる伴走を組み合わせ、**「プロダクト × データ × コンサル」**で病院経営の課題にアプローチしてきた基盤です。

より詳しい会社/事業の背景は、[MedUp 採用・求人ページ](https://medup.notion.site/recruit) を参照してください。

# 🔶 募集背景

> ### **「SaaS → データ → AI」への事業拡張を実現するため、全社・プロダクト横断の技術方針を握る責任者が必要です。**
> 複数プロダクト・統合データ基盤・AI事業を一体として見た技術戦略と、アーキテクチャ・インフラの全体設計をリードできる方をお待ちしています。

### ❑ 事業拡張に伴い、技術基盤の見直しが必要に

これまで当社は、病院経営を軸にしたコンパウンドSaaSをテーマに、複数のプロダクトを展開しながら病院経営の意思決定そのものをアップデートしてきました。

そして現在は、コンパウンドSaaSで培った統合データ基盤をさらに強化し、AI事業の本格立ち上げ・データ利活用の高度化を進めています。

アーキテクチャの見直し、データ基盤の刷新、複数モジュールの統合的な開発管理など、**これまでの延長線だけでは乗り越えられないテーマ**が増えてきています。

### ❑ プロダクトごとではなく、全体で技術的に最適な方針を

新規プロダクトの立ち上げと既存SaaSの安定運用・改善が同時に走るなか、プロダクトごとに最適な判断を積み上げるだけでは、全体の技術負債やインフラコストが膨らみます。

foro CRM をはじめとする既存プロダクト、新規のAI事業、統合データ基盤──**プロダクト横断で**技術的に最適な方針を考え、意思決定できるポジションを求めています。

### ❑ マネジメント職ではなく、技術責任者として

本ポジションは、人の評価やライン管理を担うマネジメント職ではありません。
**全社・プロダクト横断の技術方針・アーキテクチャ・インフラ・技術ガバナンス**を握る、技術側の責任者です。

将来的にはCTO候補として経営層と技術戦略を語るポジションですが、まずは**技術的に信頼できる責任者**として、プロダクト横断の技術方針をゼロから設計していただきたいと考えています。

🚩アーリーフェーズならではの裁量で、全社・プロダクト横断の技術戦略を描き、事業成長に直結させたい方を募集しています。

# 🔶 ポジション概要

> ### **全社・プロダクト横断の技術責任者（CTO候補）です。**
> 複数のSaaSプロダクト、AI事業を一体として見据え、**プロダクト横断で技術的に最適な方針**を考え、全社の技術戦略を握ります。

### ❑ このポジションで担うこと

- 複数SaaSプロダクト横断の**技術方針・アーキテクチャ方針**の策定
- 事業戦略・プロダクト戦略と**技術戦略の整合**
- 品質・セキュリティ・技術負債の**プロダクト横断**での投資判断
- 各開発チームへの**方針・優先度・標準**の提示

### ❑ こんな方にフィット

- プロダクトのアーキ・品質・技術判断を牽引した経験があり、**プロダクト横断**の技術方針に関心がある方
- 単一プロダクトではなく、**全体最適**の視点で技術を考えることに面白みを感じる方
- マネジメント職ではなく、**設計・アーキテクチャ・技術戦略**に近い裁量で働きたい方
- 医療×SaaS×AIという領域で、**CTO候補**として技術面から事業を牽引したい方
- 社会性の高いテーマに対して、技術的な介在価値を実感しながら働きたい方

# 🔶 業務内容

> ### 全社・プロダクト横断の**技術責任者として、戦略から設計・基盤・ガバナンスまでをリードする**

### 🏗 プロダクト横断の技術方針・アーキテクチャ

❑**概要**：foro CRM 等の既存プロダクト、新規プロダクト、AI事業を含む複数プロダクトで、技術的に最適な方針を策定します。

❑**実行内容**

- プロダクト横断のアーキテクチャ方針・設計
- プロダクト間の共通化や技術的負債の投資優先度づけ
- プロダクトの保守・運用体制の全体設計
- 必要に応じて顧客と直接会話し、技術視点から課題・要件を深掘り

### 🌐 インフラ・統合データ基盤

❑**概要**：プロダクト開発とインフラ・データ基盤の設計方針を決めて推進します。

❑**実行内容**

- クラウドアーキテクチャ（GCP等）の全体設計・最適化
- 開発・デプロイ・可観測性の共通基盤の方針策定
- 運用・セキュリティ基盤の全体設計

### 🎯 技術戦略・事業との整合

❑**概要**：「SaaS → データ → AI」への事業拡張に合わせ、技術ロードマップを策定し、経営層・事業責任者・プロダクト責任者と合意を取ります。

❑**実行内容**

- 事業戦略・プロダクト戦略と連動した中長期の技術戦略の立案
- AI/LLM、データ基盤など最新技術の調査・導入判断
- 各プロダクト・開発チームの状況を踏まえた全体最適の方針決定

### 🛡 技術ガバナンス

❑**概要**：品質・セキュリティ・コンプライアンスの会社方針を策定し、各チームの判断軸をそろえます。

❑**実行内容**

- 品質担保、セキュリティ強化、コンプライアンス強化の方針と推進
- 技術的負債の特定、プロダクト横断での解消計画の策定・推進
- 各開発チームへの技術方針・優先度の提示

# 🔶 このポジションの魅力

### ❑ プロダクト横断の技術方針の設計を主導できる

単一プロダクトの技術リードではなく、foro CRM・新規プロダクト・AI事業を**一体**として見た技術戦略を描けるポジションです。自分の意思でデザインできます。

### ❑ プロダクト横断の全体最適──技術方針を横断的に設計できる

foro CRM・新規プロダクト・AI事業を個別に最適化するのではなく、「プロダクト横断で何が最適か」を考え、方針を決めるポジションです。

### ❑ マネジメント職ではなく、技術責任者として裁量を持てる

人の評価やライン管理ではなく、**アーキテクチャ・技術戦略・インフラ方針**に集中できるポジションです。設計と意思決定に近い立場で、事業と技術をつなぎます。

### ❑ 医療×Vertical SaaS×AIという希少な領域で、CTO候補として成長できる

医療という専門性の高い領域で、SaaS・データ・AIを掛け合わせた技術戦略を担う経験は、キャリアとしても希少価値が高いです。将来的にはCTOとして経営層と技術を語るステップへ。

### 💡 こんな体験ができます

- プロダクト横断のアーキテクチャ方針を策定し、全社の技術の方向性を決める
- 事業戦略と技術戦略を整合させ、経営層と技術投資の優先度を議論する
- AI事業の本格立ち上げに向けた技術設計・導入方針をゼロから描く
- 開発チームと連携しながら、プロダクト横断の技術ガバナンスを確立する

# 🔶 主な使用技術

> ### プロダクト開発・インフラ・データ基盤で主に扱う技術スタックです。

- **フロントエンド**：TypeScript, React, Next.js, Zustand, React Hook Form, Zod, OpenAPI Generator, Sass, vanilla-extract, storybook, …etc
- **バックエンド**：TypeScript, Node.js, Fastify, tRPC, Prisma, Kysely, fp-ts, typebox, Python ※1, (Rails ※2), …etc
- **データベース**：PostgreSQL, BigQuery
- **インフラ・その他**：GCP (Cloud Run, AlloyDB, Cloud SQL, Cloud Build, …etc), Azure (AADB2C), Docker, Sentry, SendGrid, Figma, Cursor 等のAIコーディングツール, …etc

※1 Webアプリケーションでは TypeScript / Node.js がメイン。データ基盤構築で Python を採用しています。  
※2 以前の外注開発で使用していた Rails が一部で動いていますが、内製化後は TypeScript / Node.js へ随時切り替えています。
