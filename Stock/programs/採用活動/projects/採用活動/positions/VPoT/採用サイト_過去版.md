医療の質と持続可能性が問われ、医療機関の「変革」を支援するパートナーが求められている今、

# 🔶 募集背景

> ### **事業の急成長を目指す今だからこそ、事業・プロダクトの核となるデータ戦略をリードする力が必要です。**
> 特に、事業上の価値を生み出すために逆算して必要なデータを見極め、BI/DWHなどを利用してそのデータの利活用を推進できる方をお待ちしています。

### ❑ 2040年問題と病院の変革ニーズの顕在化

人口減少・高齢化が進む中で、現状の医療提供体制の維持が困難になる時代が迫っています。
**「病院経営の改革」は、今や国全体の喫緊のテーマ**となっています。

### ❑ 今こそ、変革のパートナーが必要

**病院経営層が本気で変化**を求め始めた今こそ、メダップの出番です。
より多くの医療機関へさらなる価値を届けるために、**『事業・プロダクト戦略を支えるデータ戦略』の考案が急務**です。

🚩アーリーフェーズならではのスピードと裁量を持って、一緒に事業を推進してくれる仲間を募集しています。

# 🔶 ポジション概要

> ### 事業・プロダクトの基盤となるデータ戦略やOps全般を担うVP候補
> 社内のデータ戦略を担うVPとして、**ユーザーに価値あるデータを提供するためのデータ戦略の策定とそれを実現するオペレーションの構築・実行を一貫してリード**していただく存在を求めています。

### ❑ こんなポジション

全社を横断してデータをリーディングする立場として、データに関する業務全般をリードいただきます。

- ユーザーデータやオープンデータ、それらの二次データの利活用提案
- 目的から逆算し、CSやユーザーを巻き込んだ必要なデータの収集
- データの利活用を実現する効率的なオペレーション構築
- マルチプロダクトからアクセスしやすいデータ基盤の設計・構築
- 事業戦略やプロダクト戦略を踏まえた中長期のデータ戦略の考案

### ❑ こんな方にフィット

- 主導的にデータの活用方法を提案し、**データを通じてユーザーに価値を届けたい方**
- 顧客の課題に深く入り込み、**上流から課題解決に取り組みたい方**
- **データドリブンな事業に面白みを感じていただける方**
- **顧客と変化を一緒に創りたい方**
- 社会性の高いテーマに対して、**自身の介在価値を実感しながら働きたい方**

このような志向をお持ちの方にフィットするポジションです。

---

# 🔶 業務内容

> ### データ戦略の立案から実装まで、全社横断でリードする役割

### 📊 データの利活用・価値創出

**概要**：病院内外の多様なデータソースから新たな価値を発見し、事業機会として具現化します。

**実行内容**

- 病院の診療実績・患者フローデータの分析と活用提案
- データを可視化するダッシュボードの作成
- 複数病院データの横断分析による新たなインサイト創出

### 🎯 データ戦略策定

**概要**：事業戦略・プロダクト戦略と連動した、中長期のデータ戦略を策定し、事業責任者やプロダクト責任者と合意を取ります。

- 医療データの利活用に関する全社戦略の立案
- データドリブンな意思決定を支える仕組みづくり
- 新規データソースの開拓と価値創出の提案
- データガバナンス・セキュリティポリシーの策定

**実行内容**

- 事業責任者やプロダクト責任者との定期的な戦略議論
- データROIの可視化と投資判断の支援
- データ取得に関するCS/PSとの連携

### 🏗️ データ基盤の設計・構築

**概要**：マルチプロダクトやデータ戦略を支えるデータ基盤を設計・構築・スケールします。

- クラウドネイティブなデータアーキテクチャ設計
- BI/DWHツールの選定・導入・運用

**技術スタック例**

- クラウド：GCP
- データ基盤：BigQuery, AlloyDB, Cloud SQL, Cloud Storage
- BI：Tableau、Power BI等

### 🔄 データオペレーションの構築・最適化

**概要**：データの収集から活用まで、効率的なオペレーションを設計・実行します。

- CS・PSチームと連携した病院データの収集スキーム構築
- データクレンジング・活用プロセスの脱属人化、自動化
- データ利活用のベストプラクティス確立

# 🔶 このポジションの魅力

### ❑ データドリブンな事業展開の中核を担える

プロダクトありきのデータ活用ではなく、**データドリブンにプロダクト・サービス開発**を推進する立場です。
病院の膨大なデータから新たな価値を発見し、それを起点に新規事業・サービスを創出する、真のデータドリブン経営を実現できます。

### ❑ 医療DXという日本の中でも注目されたテーマで、職務経験を積むことができる

継続的に質の高い医療が提供できる体制の構築を目指しており、社会的意義が大きいポジションです。
医療データの利活用という最先端領域で、業界のスタンダードを作る経験ができます。

### ❑ 経営に直結するデータ戦略をイチから構築できる

データ組織におけるデータ基盤の方針決め、アーキテクチャ設計など、単なるデータ分析の枠にとどまらず、**事業の根幹を支えるデータ戦略**を立案・実行できる環境があります。

### ❑ Vertical SaaS×データの希少なキャリアを築ける

医療という専門性の高い領域で、SaaSとデータ戦略を掛け合わせた希少価値の高いキャリアを構築できます。

### 💡 こんな体験ができます

- 病院の経営データから新たなインサイトを発見し、それを新規サービスとして具現化する
- データを起点とした意思決定文化を組織に根付かせる
- 医療業界のデータ活用のスタンダードを作り、業界全体の変革に貢献する
- 経営層・投資家に対して、データROIを明確に示しながら事業成長を加速させる

# 🔶 主な使用技術

- フロントエンド：TypeScript, React, Next.js, Zustand, React Hook Form, Zod, OpenAPI Generator, Sass, vanilla-extract, storybook, …etc
- バックエンド：TypeScript, Node.js, Fastify, tRPC, Prisma, Kysely, fp-ts, typebox, Python \*1, (Rails \*2), …etc
- データベース：PostgreSQL, BigQuery
- その他：GCP(CloudRun, AlloyDB, CloudSQL, CloudBuild, …etc), Azure(adb2c), Docker, Sentry, SendGrid, Figma, …etc

\*1 Webアプリケーションでは、TypeScript, Node.js がメインになっていますが、データ基盤構築で Python を採用しています。  
\*2 以前、開発を外注していた際に使用していた Rails が一部で動いていますが、開発組織の内製化後、メイン技術を TypeScript, Node.js に随時切り替えています。
