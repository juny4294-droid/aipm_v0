# バージョン一覧の更新手順

2026-11-09 から 2026-11-16 の調査でページを作ったときの基準を、更新の手順にしたもの。

ページは [バージョン一覧](https://app.notion.com/p/4131da5a7f3b807c8ad7d57c75bd8d9f)。

ページを直すと、次の1時間以内の `post` が「監視」が「あり」の行を読み、`watch_list` を更新する。コードの貼り替えは不要。

## 1. 版をどこから取るか

正は GitHub のデフォルトブランチ（`develop` または `main`）。手元の `medup-security-audit` は古いことがある。作業ツリーではなく、`origin` のデフォルトブランチを読む。

見るファイルは、本番へ出す最終イメージの Dockerfile、実行時の `package.json`、Gemfile、Pipfile など。ビルド段階だけの版は載せない。

Redash だけは、リポジトリの定義ではなく `redash-slackapp` で動いているコンテナの中身を正にする。2026-11-12 の確認では、compose の `redash/nginx:latest` と、VM に残っているイメージの中身が違っていた。

固定していないタグは、タグ名ではなく、動いているイメージの中の版を書く。

## 2. 載せるもの

本番の Cloud Run、Cloud Functions、Cloud Run Jobs で動き、メダップがパッチを当てるもの。

- 言語・ランタイム。TypeScript は実行時には残らないので、実行時の Node.js を書く。
- アプリサーバ。Next.js と Ruby on Rails はここに入れる。
- DB。版がリポジトリにあるもの。
- 自分たちが出す最終イメージの OS。Debian、Ubuntu、Alpine。
- Redash。自前の VM で、パッチもメダップが当てる。表は分ける。

1行に書くのは1つのバージョン。複数入っている行は分ける。リポジトリが違えば行を分ける。

## 3. 載せないもの

- 本番に載っていないリポジトリ。試作、手元だけ、CI だけ、デスクトップアプリ。
- 本番データを持たない開発環境。
- ビルドにだけ使い、本番コンテナに入らないもの。
- 版を自分たちで選ばないもの。AlloyDB、BigQuery、Cloud Run や Cloud SQL のホスト OS。
- npm ライブラリ。Dependabot が見る。
- ローカルの `docker-compose` だけにあるミドルウェア。

## 4. 行の書き方

列はこの順で残す。名前を変えると、毎時の読み取りが失敗する。

| 列 | 書き方 |
| --- | --- |
| 対象 | 製品名。取り方を足してある名前は Node.js、Ruby、Ruby on Rails、Python、PostgreSQL、Next.js、Redis、Bun、nginx |
| リポジトリ | リポジトリ名。Redash の表は `redash` |
| バージョン | 上の「版をどこから取るか」で読んだ版。1セルに1つ |
| サポート期限 | 公式のセキュリティ更新が終わる日。Debian は LTS の終了日。Ubuntu は標準サポートの終了日で、ESM の日を併記する。公式が未確定なら日付のあとに「（予定）」。公式に日付がなければ「なし」。日付は作らない |
| 監視 | 今の告知ジョブで見る行は「あり」。OS と Redash 本体は「なし」。値は「あり」か「なし」 |

表は「言語・ランタイム」「アプリサーバ」「DB」「OS」「Redash」のまま分ける。

調査日の一文は、見直した日に直す。

## 5. 書いたあとの監視

「あり」の行が前回と違えば、次の `post` が `watch_list` を上書きして、そのバージョンで告知を探す。同じなら `watch_list` は変わらない。

系列だけが同じ更新（Node.js の `22.23.4` を `22.24.0` にするなど）では、当たる告知は変わらない。DM に出るバージョン表示が変わる。

完全一致の更新（Next.js、Redis、Bun、nginx）や、新しい系列を足したときは、すでに出ている告知のうち、そのバージョンに当たるものが届くことがある。

取り方のない製品を「あり」にすると、その製品を除いて確認は続く。DM に「取り方が未定義です」と出る。取り方を足すまでは「なし」にしておく。

一覧が読めないときは `watch_list` は変わらない。前回のバージョンで告知を探し、「バージョン一覧を読めなかったので、前回のバージョンで確認しました」と DM が届く。
