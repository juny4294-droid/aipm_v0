# 入院データ投入の初期設定

## 概要

新規顧客や医療ID変更時に必要な「入院データ投入の初期設定」を、これまでエンジニアが手動（DB直書き）で対応してきた。定型作業のため **admin_web（MIS管理画面）から実行できる機能を追加**し、Slack/Asana 経由の依頼と手動作業を不要にする。
