## 入院タブ UI

```
[初期設定]  [インポート]
─────────────────────────
インポート履歴テーブル（既存）
```

| 要素 | 仕様 |
|------|------|
| **初期設定** ボタン | 常時表示。クリックでモーダルを開く |
| **インポート** ボタン | 既存どおり `availability.available` で enable/disable |
| 登録済みコード一覧 | 入院タブ本体には出さない。初期設定ボタン押下時のモーダル内に簡易一覧を出す |

`availability.available === false` のとき、インポート横に補足文言を出すかは任意（例:「初期設定を完了してください」）。

## モーダル

### タイトル
**入院データ投入の初期設定**

### 説明文
なし

### 入力項目

| 項目 | UI | 初期値 | 備考 |
|------|-----|--------|------|
| 医療機関ID | Input（必須） | 空 | `tenant_id` は URL から API に渡す（画面には出さない） |
| DPC医療機関コード | Input（必須） | 空 | `dpc_medical_institution_code` |

**表示しないもの**: テナント、医療機関名、説明文

### 登録済みコード一覧

初期設定ボタンを押して開いたモーダルの、入力エリアの下に出す。入院タブ本体には出さない。

- 見出しは「登録済み」
- 当該テナントに登録済みの **医療機関ID** と **DPC医療機関コード** を列挙する
- 列の項目名は不要。値を並べるだけでよい
- 0件のときは「登録済み」自体を出さない
- 登録に成功したら、開いたままのモーダルの一覧にその行を足す

### ワイヤー

```
┌─ 入院データ投入の初期設定 ─────────┐
│                                    │
│ 医療機関ID *                       │
│   [              ]                 │
│                                    │
│ DPC医療機関コード *                │
│   [              ]                 │
│                                    │
│ 登録済み                           │
│   40156  145402565                 │

└────────────────────────────────────┘
```

### ボタン

| ボタン | 動作 |
|--------|------|
| キャンセル | モーダルを閉じる |
| 登録 | 下記「登録フロー」参照 |

`登録` は医療機関ID・DPCコードが入力済みで enable（重複は登録時に API で判定）。

### 登録フロー（確定）

```
[登録] クリック
  → API 呼び出し（tenant_id は URL から付与）
  → 重複チェック（同一 tenant_id + medical_institution_id + dpc_medical_institution_code）
      ├─ 重複あり → モーダル内にエラー表示（モーダルは開いたまま）
      └─ 重複なし → INSERT → モーダル内に成功表示
                      → availability 再取得
                      → ユーザーが手動でモーダルを閉じる
```

| 結果 | モーダル表示 | その他 |
|------|-------------|--------|
| **重複・失敗** | エラーメッセージ（例:「既に登録されています」） | モーダルは開いたまま。入力値維持。修正して再登録可 |
| **成功** | 成功メッセージ（例:「初期設定を登録しました」） | availability 再取得。モーダルは **ユーザーが手動で閉じる**（自動クローズしない） |

※ 成功・失敗ともフィードバックは **モーダル内** に表示（トーストのみにはしない）

### クライアント側バリデーション（登録前）

- 医療機関ID: 必須・数値
- DPC医療機関コード: 必須・数字のみ

### サーバー側（登録時）

- 重複チェック: **`tenant_id` + `medical_institution_id` + `dpc_medical_institution_code` の3つ組み合わせ**が既存ならエラー返却
- 重複なし: `tenant_medical_institution_code_ids` に INSERT
- **複数登録**: 1テナントに複数行あり得る
  - パターンB: 同一 tenant + 同一 medical_institution + **別 DPC**（広尾）
  - パターンC: 同一 tenant + **別 medical_institution** + 別 DPC（医療機関ID変更等）
  - 重複は3項目すべて一致時のみエラー
- 削除機能: 今回スコープ外

### 権限（確定）

- **入院タブを利用できるユーザー** であれば「初期設定」ボタンも利用可能
- 追加の権限設定・ロール分けは **不要**（既存の foro Core Admin / 入院タブのアクセス制御に準拠）
- **監査ログ**: 不要（今回考慮しない）。`created_at` 等の DB 既定値のみ

- モーダル: `HospitalAdmission/components/UploadFileModal`

## 複数登録パターン（確定）

1テナントに対して `tenant_medical_institution_code_ids` は **複数行あり得る**。重複は **3項目すべて一致** のときのみエラー。

| パターン | tenant | medical_institution_id | dpc_code | 例 |
|----------|--------|------------------------|----------|-----|
| **A. 初回登録** | 新規 | 新規 | 新規 | 川崎市立多摩（517 / 40156 / 145402565） |
| **B. 同一医療機関に DPC追加** | 同一 | 同一 | **別** | 広尾（516 / 25786 / `136070007` を追加） |
| **C. 別医療機関を追加** | 同一 | **別** | 別 | 医療機関ID変更・複数施設など |

### 広尾ケース（パターン B）

[議事メモ](https://app.notion.com/p/3c91da5a7f3b80a58b2bdd271c09566e) 依頼2「**追加で医療機関コード追加**」。

| 項目 | 値 |
|------|-----|
| テナントID | 516 |
| 医療機関ID | 25786（既存と同一） |
| 追加する DPCコード | `136070007` |

### 別医療機関ケース（パターン C）

同一テナントに対し、**別 `medical_institution_id` + 別 `dpc_medical_institution_code`** の組み合わせでも登録可能（医療機関ID変更時など）。

### 重複判定まとめ

```
エラーになるのは:
  tenant_id + medical_institution_id + dpc_medical_institution_code
  の3つがすべて既存行と一致したときのみ

それ以外（いずれか1つでも違えば）→ 登録可
```
