## 1. プロジェクトの趣旨

| 現状 | あるべき姿 |
|------|-----------|
| 新規顧客・医療ID変更のたびに CS/PS から依頼が来る | 依頼自体が不要 |
| エンジニアが `data_ops_prd` に SQL を直書き | **admin_web（MIS管理画面）** から誰でも（権限内で）実行できる |
| 入院データのバリデーション設定レコードを DB に直接 INSERT するしかない | 定型 INSERT を画面操作に置き換える |

> 入院データのバリデーション設定のレコードが DB に直接書き込む以外手段がないので現状エンジニア以外できない。定型の SQL を実行するだけなので MIS 管理画面から実行できるように機能追加したい。

---

## 2. いつ発生するか

- **新規顧客**のオンボーディング時（初回登録）
- **医療機関IDの変更**時（別医療機関ID + 別DPCコードの追加）
- **同一医療機関への DPCコード追加**時（広尾ケース）

---

## 3. 現行の手動作業（As-Is）

### やっていること

`data_ops_prd.tenant_medical_institution_code_ids` に **1行 INSERT** するだけ。

```sql
INSERT INTO tenant_medical_institution_code_ids(
  id, tenant_id, dpc_medical_institution_code, medical_institution_id, created_at, updated_at
)
VALUES(
  gen_random_uuid(), '<tenant_id>', '<dpc_medical_institution_code>', <medical_institution_id>, now(), now()
);
```

## 4. To-Be（機能追加の方向性）

- **配置**: foro Core Admin → テナント詳細 → **入院タブ**（`/foro-core/tenants/{id}?tab=hospitalAdmission`）
- **ボタン**: 「**初期設定**」→ モーダルで登録（登録済み一覧は今回は出さない）
- **admin_web** に初期設定用 UI / API を追加
- 入力: `tenant_id` / `medical_institution_id` / `dpc_medical_institution_code`
- 実行: 上記 INSERT をアプリ経由で行う（エンジニアの DB 直アクセス不要）

詳細: [画面・モーダル案](./画面・モーダル案.md)
