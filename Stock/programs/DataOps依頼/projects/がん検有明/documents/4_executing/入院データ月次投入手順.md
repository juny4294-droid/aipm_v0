## 変換ルール

有明はDPCを厚生局提出用に匿名化したデータしか出せない。IT推進課の匿名化は、診療系IDの頭の0を削り、末尾に0を足す。

| | 例 |
|---|---|
| 診療系ID | `0007925233` |
| 受領するDPC識別番号 | `0079252330` |
| 投入前に戻す | `0007925233` |

復号は、末尾の `0` を除き、元の桁数になるよう先頭を0埋めする。様式1とDファイルの両方にかける。施設コードの次列（2列目）がデータ識別番号。

出力ファイル名は `*_patient_number_fixed`。

前回（2026-09）の確認で、`0000201310` → `0000020131` がこのルールどおりだった。逆方向（末尾に0を足す）にはしない。

## 毎月の手順

受領ファイルは Stock に置かない。その月の Flow 日付フォルダを作業場所にする。

1. Drive から様式1とDファイルを月ごとに取得し、作業フォルダの `input/` に置く。片方しかない月は投入せず、CSへ連絡する
2. dry-run で件数とサンプルを見る
3. 本実行し、`output/*_patient_number_fixed*` を作る
4. 変換結果を確認する
   - 例: `0079252330` → `0007925233`
   - 変換0件なら止める。列位置が違うか、既に変換済みの可能性がある
   - ヘッダ行の2列目が識別番号でなければ、ヘッダはそのまま残る
   - 変換した列以外が元ファイルと一致している
5. [入院タブ](https://admin-web.medup-core-service.com/foro-core/tenants/204?tab=hospitalAdmission) で対象月の登録有無を見る。未登録なら変換後ファイルを月ごとにインポートする。登録済みの月を入れ直すときは、その月を削除してからインポートする
6. レコード数・入院紹介数・dpcコード数が、直近月と比べて差分20%以内かを見る。20%は [入院データ投入手順](https://app.notion.com/p/2651da5a7f3b80c99cf8e94756160a4a) の投入後チェック。エラーが出たら黒川さんへ連絡する
7. 完了処理
   - [データ受領/投入状況一覧](https://admin-web.medup-core-service.com/foro-core/data-importing-logs) に、入院（様式1）とDファイルの該当月を作成し、受領済みにする
   - Asana `04_データ投入ops` のステータスを Imported にし、タスクを完了する
   - Slack の依頼スレッドに完了を返す

ファイル名の並びは `FF1_130870923_YYMM`（様式1）と `Dn_130870923_YYMM`（Dファイル）。`YYMM` は対象月（例: 2026年8月は `2608`）。

### コマンド

```bash
SCRIPT="Stock/programs/DataOps依頼/projects/がん検有明/documents/4_executing/convert_patient_number.py"
WORK="Flow/202610/2026-10-23/DataOps依頼_がん検有明"
mkdir -p "$WORK/input" "$WORK/output"
python3 "$SCRIPT" --input-dir "$WORK/input" --output-dir "$WORK/output" --dry-run
python3 "$SCRIPT" --input-dir "$WORK/input" --output-dir "$WORK/output"
```

`WORK` はその回の Flow 日付フォルダに読み替える。引数を付けないと、スクリプトと同じフォルダに `input/` と `output/` を作る。
