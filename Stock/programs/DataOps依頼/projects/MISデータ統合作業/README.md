# MISデータ統合作業

## 概要

手動登録などで厚生局の指定一覧に載らない医療機関が、正規の厚生局レコードと二重に MIS に残る。月次更新のあと、その重複を見つけて統合する。

2026-10 はほりいけ呼吸器内科クリニックを統合済み。次月以降は統合作業手順に従う。
