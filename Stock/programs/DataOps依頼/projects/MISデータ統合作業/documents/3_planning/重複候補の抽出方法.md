# 重複候補の抽出方法

2026-10-07 時点。8月の統合作業メモと、`MedUpInc/data-customer-ops` の突合実装を突き合わせた。

重複ペアを一発で返すクエリはない。前々回の作業ブック [20260804_重複候補](https://docs.google.com/spreadsheets/d/1FX7KDjR11VVgxFxtvJ1VckRzLZfzC5vJMc1JV8i6oOU/edit?gid=1848597190#gid=1848597190) の先頭タブ名が、抽出条件そのものになっている。

> 新規の届け出に記載もなく、指定一覧に対応するデータもないにもかかわらず、status が open であるデータ

その一覧を目検して、対応カテゴリを `重複` / `届け出まち` / `医科歯科以外` に分ける。`重複` だけが統合作業の対象。

## 1. イレギュラー（MISのみ）を出す

実装は [update-mis/src/all_list.py](https://github.com/MedUpInc/data-customer-ops/blob/main/update-mis/src/all_list.py)。Pipfile のスクリプト名は `all-list`。

```bash
# update-mis/ で、一覧xlsxがあるディレクトリを渡す
pipenv run all-list <一覧ファイルのディレクトリ>
```

突合キーは `medical_institution_code`。MIS 側の母集団は [get_facilities.py](https://github.com/MedUpInc/data-customer-ops/blob/main/update-mis/src/gateways/db/get_facilities.py) の次の条件。

- `medical_institutions.status_id = 1`
- `medical_institution_facility_types.facility_type_id IN (1, 2, 3)`（病院・診療所・歯科）

出力は `update-mis/output/` に4ファイル。

| ファイル | 意味 |
| --- | --- |
| `*_mhlw_all_list.csv` | 厚生局の指定一覧（整形後） |
| `*_only_exist_in_mhlw.csv` | 厚生局にだけある（MISに同じコードがない） |
| `*_only_exist_in_mis.csv` | **MISにだけある。これがイレギュラー** |
| `*_dif_facility_list.csv` | 同じコードが両方にあり、名称・住所・電話・開設者・管理者・診療科のどれかが違う |

`only_exist_in_mis.csv` の列は `medical_institution_code`, `medical_institution_id`, `name`, `address`, 電話、開設者、管理者、`raw_department_string`。

前提の一覧CSVは、同じリポジトリの `extract-overview`（`extract_from_overview.py`）で厚生局Excelから作る。月次の流れは [20260818_MIS月次作業](https://app.notion.com/p/3c01da5a7f3b80779567c2e9ca944fc1)。厚生局ファイルの格納先は [Drive](https://drive.google.com/drive/folders/1-BeEQGktTthtjLwd6_FZNMFw-gkr1bJe)。

2025-06 の振り返りでは、突合母集団を「医科歯科かつ開院・休止」と書いている。コードが切っているのは `status_id = 1` だけなので、休止が 1 に含まれるかは今月実行前に確認する。

## 2. イレギュラーを MIS で検索して、複数Hitだけ残す

[20260804 のメモ](https://app.notion.com/p/3b21da5a7f3b80589405c34f4f5a6aa0) の手順。

1. イレギュラー施設を MIS 管理画面で名称検索する
2. 複数Hitしたら重複。どちらかに寄せる
3. 残すのは、厚生局側の10桁医療機関コードが付いている方
4. 1件しかHitせず、医療機関コードが `0` や `1` のものは、手動登録の新規開院待ちであることが多い。重複ではない

8月の作業ログでの切り分け例。

| 施設 | 判定 |
| --- | --- |
| セタファミリークリニック（409670） | 2件Hit。正規コードの 104502 を残し、409670 を統合対象 |
| うえだ在宅ケアクリニック（409912） | 2件Hit。正は 410042。foro 側に重複データはなく、409912 のアーカイブのみ |
| 六町ハートクリニック、築地駅前内科 など | 1件Hit、コード `1`。開院告知はあるが届出前。統合しない |
| 中野みらい矯正歯科（409851） | 名称は1件、住所で別ID（147055、コード `0`）。自費のみと判断し統合していない |

この名称検索は `all_list.py` には入っていない。管理画面での目検。

## 今月やるときに外しやすい点

- 名称変更はコード突合では出ない。イレギュラー抽出の対象外（20260708 メモ）
- アーカイブ済みなのに医療機関コードが残っていると、月次取り込みが `medicalInstitutionCode / duplicated` で落ちる。アーカイブ時はコードを `0` にする（20260818）
- 新規指定一覧にあって指定一覧にない施設を insert すると休止になる。1ヶ月後の差分で救えるが、当月に直すなら別SQL
