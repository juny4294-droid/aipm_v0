# DataOps依頼

DataOpsへの個別依頼を管理するプログラムです。

依頼ごとにプロジェクトを作成し、対応内容・経緯・成果物を整理します。

## 使い方

1. 新しい依頼が来たら、本プログラム配下にプロジェクトを追加する（例: 「〇〇病院_紹介データ抽出」）
2. 作業メモ・下書きは `Flow/` 側、確定版は各プロジェクトの `documents/` に置く
