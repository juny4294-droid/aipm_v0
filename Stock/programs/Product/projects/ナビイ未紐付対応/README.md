# ナビイ未紐付対応

## 概要
ナビイ（医療情報ネット）からスクレイピングしたデータを、foro CRM の医療機関マスタへ正しく紐付ける。現行の3ID一致（名称・住所・電話番号）では約1万件が未マッチのため、誤紐付けを避けつつ合致条件を見直し、未紐付けを減らす。
