## 1. この面接のゴール

**ゴール**:

- **一緒に働きたいか**を見極める。
- **信頼して任せられる能力**があるかを見極める。
- 応募者の**転職軸**（転職理由、重視すること、キャリア志向、譲れない条件）を把握する。
- その転職軸が、**メダップ/FDEで実現可能か**をすり合わせる。
- 可能な範囲で候補者へ**アトラクト**する。

**前提**: 二次面接では、代表プロジェクトの再深掘りや網羅的なスキルチェックは行わない。顧客デリバリーの現場で一緒に動く相手として、**一緒に働きたいか・信頼して任せられる能力**をメインに見る。転職軸・マッチもあわせてすり合わせる。

## 3. 面接官向け：二次面接で特に見ること

### 二次面接の位置づけ

二次面接では、**Trust（協働・信頼）**と**Growth（フィードバック・成長）**を中心に見る。あわせて、候補者の**転職軸**を聞き、**メダップ/FDEとのマッチ**をすり合わせる。

### 1. 一緒に働きたいか（Trust）

**見ること**: 同じチーム・同じテーブルで、一緒に働きたい・働きやすそうか。

- 協働スタイル、コミュニケーションの取り方

**進め方**: 日常連携する同僚・責任者の視点で、人柄・仕事の進め方・相性を見る。CS/PS、開発、現場など立場の違う人との協働経験を具体例で聞く。

### 2. 信頼して任せられる能力（Trust）

**見ること**: 業務を任せて、報告・相談・完遂まで信頼できるか。

- 曖昧な状況でも自走し、必要なタイミングで報連相できるか
- 約束したことをやり切った経験、信頼関係を築いた経験があるか
- 任された範囲を越えて手を広げすぎないか／足りないとき相談できるか

**進め方**: 任せたい業務（顧客対応、要件整理、推進、実装の一部等）をイメージしながら、過去の具体例で確認する。

### 3. フィードバック・成長（Growth）

**見ること**: 指摘や方針変更を受け止め、自らアップデートし続けられるか。

- フィードバックの受け止め方、方針変更への対応

**進め方**: 協働エピソードの中で、方針変更や指摘があった場面を具体例で聞く。

### 4. 転職軸・メダップ/FDEとのマッチ

**見ること**: 転職理由・重視すること・キャリア志向が明確か、メダップ/FDEとしてズレがなさそうか。

- 転職理由と重視することに優先順位があるか
- 本人のキャリア像とFDEの役割に大きなズレがないか
- 目指すキャリアの魅力と不安を本人がイメージできているか

**進め方**: 深掘りしすぎず、意思決定の軸と納得感を確認する。

## 4. 60分アジェンダ（標準）

一次面接のスキル深掘りは行わない。**1つの協働エピソードを軸に会話で膨らませ、足りない観点だけ質問表（セクション6）で補う。**

| 内容 | 時間 |
|------|------|
| 挨拶 | 0:00-0:05 |
| 協働エピソード深掘り（Trust / Growth） | 0:05-0:25 |
| 転職軸・マッチ・条件 | 0:25-0:40 |
| 候補者からの質問 | 0:40-0:55 |
| 終了前確認 | 0:55-1:00 |

### 協働エピソード深掘り（0:05-0:25）の進め方

- 協働エピソードを1つ選んでもらい、会話の流れに沿って深掘りする（質問表は道具として使う）
- 同じエピソードで**Trust / Growth**の両方を見る
- 出なかった観点・申し送りの懸念があれば最後に補う

## 6. 質問表

### 一緒に働きたいか（Trust）

- **CS/PS、開発、現場など立場の違う人と進めた仕事で、うまくいったこと／難しかったことは何ですか？**  
  協働スタイルと折衝力を見る（Trust）。
- **「指示どおりに作る」のと「一緒に要件や仕様を決める」の、経験の比率はどう感じていますか？**  
  CS/PSと同じテーブルで動けるかを見る（Trust）。

### フィードバック・成長（Growth）

- **方針変更や指摘が入ったとき、どう受け止めて前に進めますか？**  
  フィードバックへの向き合い方を見る（Growth）。

### 信頼して任せられる能力（Trust）

- **曖昧な状況で、自分で判断して前に進めた経験を教えてください。どこで相談しましたか？**  
  自走力と報連相のバランスを見る（Trust）。
- **任された仕事を、期限・品質を守りながらやり切った具体例はありますか？**  
  信頼して任せられる実績を見る（Trust）。
- **関係者から信頼された／任されたと感じた経験はありますか？**  
  他者からの信頼の築き方を見る（Trust）。
- **一次面接で出ていた（　　　）について、任せるうえで確認したいのですが、もう少し教えてください。**  
  申し送りの懸念点を補完する。

### 転職軸・マッチ（あわせて）

- **今回転職を考えた理由と、転職先選びで重視していることを教えてください。**  
  転職軸の解像度を見る。
- **メダップ/FDEのどこに魅力を感じ、どこに不安がありますか？**  
  転職軸と募集内容の接続を見る。
- **CS/PSと同じテーブルで顧客課題に入り、実装・改善まで進める役割です。ご自身の転職軸と接続できそうですか？**  
  役割理解とマッチを見る。

### 条件・クロージング

- **入社可能時期、働き方、年収条件について、現時点の希望を教えてください。**  
  条件面のすり合わせを行う。
- **メダップ/FDEについて、前向きに進められそうか、率直にどう感じていますか？**  
  最終面接への温度感を確認する。

## 7. 見極め観点

### 一緒に働きたいか

- 見ること: 同じチーム・同じテーブルで、一緒に働きたいか
- 強いサイン: 協働スタイルが具体例で語れる。フィードバックを前向きに受け止められる
- 懸念サイン: 役割や指示が曖昧だと動けない、他者任せの説明が多い

### 信頼して任せられる能力

- 見ること: 業務を任せて、報告・相談・完遂まで信頼できるか
- 強いサイン: 自走と報連相のバランスが取れている。やり切った具体例がある
- 懸念サイン: 自走のみで相談が少ない、または逆に判断が遅い

### 転職軸

- 見ること: 転職理由、重視すること、キャリア志向が明確か
- 強いサイン: なぜ転職するか、何を優先するかを自分の言葉で語れる
- 懸念サイン: 転職理由が曖昧、条件面だけが軸になっている

### メダップ/FDEとのマッチ

- 見ること: 転職軸がメダップ/FDEで実現可能か
- 強いサイン: 転職軸とFDEの役割・事業領域が自然に接続している
- 懸念サイン: 求める役割像とFDEの実態に大きなズレがある

### アトラクト

- 見ること: 最終面接・入社意向を高められる余地があるか
- 強いサイン: 不安点を言語化でき、メダップ/FDEへの関心が残っている
- 懸念サイン: 一次より温度感が下がっている

