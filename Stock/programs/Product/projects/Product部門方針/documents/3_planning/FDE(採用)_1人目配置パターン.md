## 2. 背景 — いま何が起きているか

### 2-1. 組織の現状（確定に近いこと）

```
Product部門（山田：部門Mgr / PdM）
├── foroチーム（康 他）— 既存SaaSの維持・改善
├── FDEチーム（探索）— 顧客課題の深掘り〜実装〜効果確認
│   └── 黒川（FDEメイン + DataOps兼務）← すでにFDE業務に参画中
├── テックリード（採用中）— AI環境・技術横断
└── 馬場 — インフラ・セキュリティ・AI駆動開発推進
```

**FDEの日常の主戦場**（配置が未確定でも共通）:

```
FS/CS ──→ 顧客接点・課題深掘り
              ↕ 同じテーブル
           FDE ──→ 設計・実装・効果確認
              ↓ 定常化後
           foroチーム ──→ 保守・拡大
```

### 2-2. 未確定・要議論（Product部門方針 §2-2 より）

- [ ] FDEチームの**最初のプロダクト範囲**（入退院 / AI DPC / 新規事業）

### 2-3. なぜ3パターンに分かれたか

候補者のバックグラウンド・志向・シニアリティが異なり、**入社後の期待役割**が3通りに収束した。

| パターン | 候補者の典型像（例） |
|----------|---------------------|
| **A** | 顧客折衝×実装の実行者。FDEメンバーとして現場で型を作る |
| **B** | FDE/類似ロールのリード経験者。チーム立ち上げ・黒川さんの上に立つ |
| **C** | **1人目FDE**であり**Product部門責任者**を兼ねる。部門全体（foro + FDE + 横断）を束ねつつ、FDEとして現場にも入る |

## 3. 配置パターンの定義

**MTG用サマリー**（[Notion](https://app.notion.com/p/3951da5a7f3b804cb982f02fceabfa97)）:
- **A**: 黒川さんとコンビ or 黒川さんの下
- **B**: FDEチームリード（組織マネジメントは山田）
- **C**: FDE組織マネジメントまで担える
- **C'**: T/L＆FDE（MG山田・リード1人目）
- **C"**: VPクラス（MG1人目・FDEリード山田）

いずれも**採用するのは1人目FDE**。違いは入社後に被せる**帽子の数と広さ**。

| パターン | 1人目FDEとして | 追加の帽子 |
|----------|---------------|-----------|
| **A** | FDEメンバー（現場で型を作る） | なし |
| **B** | FDEリード（FDEチームPM） | FDEチームPM |
| **C** | FDE（現場にも入る） | **Product部門責任者** |
| **C'** | FDE + foro/FDEリード | T/L＆FDE |
| **C"** | VPクラス（部門横断MG） | foro/FDE MG（FDEリードは山田） |

### パターン A — 黒川さんと同列、または黒川さんの下

**定義**: 1人目FDEは**実行メンバー**。黒川さんとペアで案件を回す。入社初期は黒川さんの下、早期に同列へ、もしくは最初から同列。**FDEチームのPM**（案件・優先度・進め方）は**山田**が担う。**組織マネジメント**も山田。

```
山田
 ├── foroチーム
 └── FDEチーム
       ├── 黒川
       └── 1人目FDE（メンバー）
```

| 項目 | 内容 |
|------|------|
| **1人目の役割** | CS/PSと同じテーブルで1テーマを完遂。FDEの型を**現場から**言語化 |
| **黒川さんとの関係** | メンター / ペア / 先陣（案件によって役割分担） |
| **FDEチームPM** | 山田（案件・優先度・進め方） |
| **組織マネジメント** | 山田（評価・1on1・採用プロセス等） |
| **評価ライン** | 山田（＋黒川さんからのフィードバック） |

**入社後90日の到達イメージ**:

- 1案件で課題の構造化→改修→効果確認まで完遂（または同等）
- CS/PSと共同で動く「進め方の型」のたたき台に参画
- FDEの責務・非責務が言語化され始めている

---

### パターン B — 黒川さんの上司（FDEリード）

**定義**: 1人目FDEは**FDEチームのPM**（案件・優先度・進め方・CS/PSとの接続）。黒川さん（＋将来のFDEメンバー）の上司としてチームを回す。**組織マネジメント**（評価・1on1・採用プロセス等）は**山田**が担う。

```
山田
 ├── foroチーム
 └── FDEチーム
       リード：1人目FDE
       └── 黒川
```

| 項目 | 内容 |
|------|------|
| **1人目の役割** | FDEチームのPM：立ち上げ・案件アサイン・CS/PS/foro境界の調整・型の標準化（現場にも入る） |
| **黒川さんとの関係** | 1人目がFDEチームPM、黒川さんがシニアメンバー |
| **FDEチームPM** | 1人目FDE |
| **組織マネジメント** | 山田 |
| **評価ライン** | 山田 → 1人目FDE → 黒川（FDEチーム内のPMラインは1人目） |

**入社後90日の到達イメージ**:

- FDEチームの運営ルール（案件の入り方、CS/PS/foroの境目）が文書化されている
- 1件以上の顧客課題がFDE経由で完遂に向かっている
- 2人目FDEの要件・採用計画のたたき台がある
- 1人目自身の顧客現場時間は週○%以上（要定義）

---

### パターン C — 1人目FDE かつ Product部門責任者

**定義**: 1人目FDEが**Product部門の責任者**も担う。foro + FDE + 横断を束ねつつ、**FDEとしてCS/PSと同じテーブルで案件にも入る**。

**FDE現場の時間確保**: 部門責任者業務を**山田さん（現・部門Mgr）と分担**し、1人目はプロダクト・プロジェクト側に集中できるようにする。

```
山田
 └── foroチーム

1人目FDE
 └── FDEチーム
       └── 黒川
```

| 項目 | 内容 |
|------|------|
| **1人目の役割** | **プロダクト・プロジェクト責任**: FDE/foroの方向性、投資配分、顧客案件（CS/PSと同じテーブル）、FDEの型づくり<br>**部門責任者**: 部門全体の意思決定・対外（CEO/経営との接続） |
| **山田さんの役割（案）** | **組織責任**: foroチームの日常運営支援、採用プロセス、1on1・評価運用、部門内調整、PdM業務 等 |
| **黒川さんとの関係** | 1人目の直下。FDE案件では同列 or 黒川さんとペア（案件による） |
| **評価ライン** | CEO/経営 → 1人目FDE（山田は組織責任として1人目と連携） |

#### パターンC — 山田さんとの役割分担案

**分割の考え方**: 「**プロダクト・プロジェクト責任**」と「**組織責任**」で切る。1人目がFDE現場に入る時間を、**組織側を山田が担う**ことで確保する。

| 領域 | 1人目FDE（プロダクト・プロジェクト） | 山田（組織責任） |
|------|--------------------------------------|------------------|
| **FDE** | 顧客案件への参画、CS/PSとの深掘り、FDEの型づくり、FDE採用の要件・判断 | 採用プロセス運用、オンボーディング支援 |
| **foro** | 優先度・方向性の判断、FDE/foro境界 | チーム日常運営、自律スクラム推進、エスカレーション受け |
| **部門全体** | 投資配分（foro/FDE）、部門方針の実行、CEO/経営との接続 | 評価・1on1、リソース調整、部門内コミュニケーション |
| **PdM** | プロダクト判断（FDE案件中心） | 既存foro向けPdM業務の継続 |

**議論時に決めること**:

- [ ] 上記の切り分けでよいか（具体項目の追加・変更）
- [ ] 山田さんの肩書・評価ライン（1人目の右腕 / 引き続きMgr相当 等）
- [ ] 1人目のFDE現場時間の目安（例: 週2〜3日）
- [ ] 移行期間（最初の90日は山田主導で組織、1人目はFDEに集中 等）

**入社後90日の到達イメージ**:

- **1人目本人がFDEとして**1テーマに参画し、完遂に向けて進んでいる（黒川＋CS/PSと共同）
- 山田との役割分担が文書化され、実際に回り始めている
- foroチームの自律運営状況が可視化され、改善アクションが動いている（山田主導）
- 部門の投資配分（foro / FDE）の方針が言語化されている（1人目主導）
- FDEの責務・進め方の型が言語化され始めている

**パターンCの本質**: **1人目FDEに部門責任者の帽子も被せる**が、**組織運営は山田と分割**してFDE現場の時間を確保する。候補者には「FDEとして現場に入りながら、Product部門の責任者として方向性を握る。組織の日常運営は山田と分担」と説明する。

**議論の焦点**: ① 候補者がプロダクト・プロジェクト責任 + FDE現場を担えるか ② 山田との分担で組織が回るか ③ 候補者がこの分担モデルに納得するか

### パターン C' — T/L＆FDE

**定義**: 1人目FDEは**T/L＆FDE**。**foro・FDEともMGは山田**、**foroリード・FDEリードは1人目FDE**。

```
山田
 ├── foroチーム
 │     リード：1人目FDE
 └── FDEチーム
       リード：1人目FDE
       └── 黒川
```

| 項目 | 内容 |
|------|------|
| **1人目の役割** | foro・FDEの**リード**（現場・進め方）。FDEとして案件にも入る |
| **山田さんの役割** | foro・FDEの**マネジメント** + 組織マネジメント |
| **Cとの違い** | C=1人目がFDE MG / C'=山田がFDE MG・1人目がforoリードも担う |

---

### パターン C" — VPクラス

**定義**: 1人目FDEが**VPクラス**。**foro・FDEのMG・foroリードは1人目**、**FDEリードは山田**。

```
1人目FDE
 ├── foroチーム
 └── FDEチーム
       リード：山田
       └── 黒川
```

| 項目 | 内容 |
|------|------|
| **1人目の役割** | 部門横断の**マネジメント**（foro + FDE）。FDE現場は山田リード下で参画も |
| **山田さんの役割** | FDE**リード** + 組織マネジメント |
| **C'との違い** | C'=MG山田・リード1人目 / C"=MG1人目・FDEリード山田 |

### 4-3. リスク

| パターン | 主なリスク | 起きやすい条件 |
|----------|-----------|---------------|
| **A** | 2人目来るまでFDE「チーム」として弱い。黒川さんのメンター時間不足 | DataOps兼務が忙しい、1人目の自走が遅い |
| **B** | 1人目の現場時間 vs Mgr業務のトレードオフ。黒川さんとの関係再設計 | リード経験はあるが医療/CS連携が浅い |
| **C** | FDE現場と部門責任の時間競合 | **山田が組織責任を担う分担モデル**で緩和。分担が機能しないと現場時間が削られる |
