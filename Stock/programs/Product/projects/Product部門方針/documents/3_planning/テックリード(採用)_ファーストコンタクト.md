# テックリード（採用）転職サイト・ファーストコンタクト

> **用途**: 転職サイト（Wantedly、ビズリーチ、Green、YOUTRUST 等）で候補者へ送る **初回スカウト文のテンプレート**（ローカル専用）  
> **送信者**: 開発部門責任者の山田（テックリードスカウトは山田名義）  
> **JD**: [テックリード(採用)_要件.md](./テックリード(採用)_要件.md) / [Notion JD](https://www.notion.so/3731da5a7f3b81b18c52eb882ce5cf53) / [採用ハブ](https://medup.notion.site/recruit)

## 1. この文書の位置づけ

| 文書 | 役割 |
|------|------|
| `テックリード(採用)_要件.md` | 公開JD・採用要件 |
| `テックリード(採用)_カジュアル面談.md` | 初回カジュアル面談の進め方 |
| **本ファイル** | 転職サイト初回メッセージの**型とコピペ用テンプレ** |

**ゴール**: 返信・カジュアル面談予約。確定年収・入社オファーは書かない。

**文字数**: 初回スカウトは **1,000字以内**（改行含む。送信前に媒体のカウンタで再確認）

---

## 2. 媒体別の装飾（コピペ時の注意）

スカウト本文は **プレーンテキスト前提** で書く（§4の `text` ブロックをそのまま貼る）。

| 使わない（多くの媒体で無効 or 崩れる） | 使ってよい |
|--------------------------------------|------------|
| `**太字**`、`*斜体*`、Markdown見出し | URL（そのまま1行） |
| 文字色・背景色 | 改行・空行 |
| HTMLタグ | 「」での強調 |

---

## 3. テックリード用：タイトル（本文1行目）

**件名欄は使わない前提**。メッセージの **先頭1行** にタイトルを置き、2行目から挨拶（§4）。

### 標準（これを使う）

```text
AI駆動開発の土台を作り、医療プロダクトの品質・セキュリティを支えるテックリード募集について
```

別案: `【メダップ】部門横断で開発基盤・品質・セキュリティを作るテックリード募集`

---

## 4. テックリード用：送付文テンプレ（コピー用・1,000字以内）

**送信者**: 開発部門責任者の山田。括弧は候補者名・プロフィール具体のみ埋める。  
**装飾**: 太字・色なし。URLのみ行単位で貼る。  
**構成**: §3タイトル → 空行 → 挨拶〜  
**目安**: テンプレのまま約800字。具体①②を埋めても **1,000字以内**を目安にする。

```text
AI駆動開発の土台を作り、医療プロダクトの品質・セキュリティを支えるテックリード募集について

はじめまして！メダップ開発部門責任者の山田です。

（氏名）さんの（媒体名）の経歴（とコメント）を拝見し、（具体①）に非常に魅力を感じ、思わずご連絡しました。

メダップでは現在、病院向けSaaSの安定運用・改善と、病院特化型AIワークフローの新規開発の両方を進めています。少人数かつAI駆動で開発速度を上げていく一方で、品質・セキュリティ・運用をチームで継続的に担保できる土台づくりが重要になっています。

今回探しているテックリードは、部門共通のAI駆動開発の型、レビューや品質ゲート、セキュリティ運用、技術負債への向き合い方を設計し、日常の開発に定着させていく役割です。単に技術方針を決めるだけでなく、チームが継続的に高品質で開発できる状態を作るポジションです。

（氏名）さんの（具体②）のご経験は、弊社にとって大きな力になるのではないかと思っています。ぜひ一度お話しできないでしょうか？

弊社は約14億円（プレシリーズBまで）を調達し、「医療版LayerX/Palantir」を目指すスタートアップです。病院経営の変革を支えるプロダクトだからこそ、技術品質やセキュリティの信頼性が事業価値に直結します。

募集概要：
https://www.notion.so/3731da5a7f3b81b18c52eb882ce5cf53
https://medup.notion.site/recruit

「医療」という複雑で社会貢献性の高い領域で、開発組織の土台づくりから事業成長に関わるテーマです。ご興味があれば、ぜひオンラインでカジュアルにお話しさせてください。

もしご興味を持っていただけましたら、ご返信もしくは以下の日程調整リンクよりご予約いただけましたら幸いです。

お返事お待ちしております。
```

## 5. パーソナライズ差し替え（具体①・具体②）

§4の `（具体①）` `（具体②）` に貼る。合計で **1,000字以内** に収める。

| 候補者の傾向 | 具体①の例 | 具体②の例 |
|-------------|-----------|----------------|
| テックリード/リードエンジニア | 技術選定や設計レビューをリードされてきたご経験 | チームの技術判断を前に進めてきた |
| EM/開発組織改善 | 開発プロセスやレビュー体制を整えてきたご経験 | 個人の頑張りではなくチームが回る仕組みを作ってきた |
| セキュリティ/品質 | セキュリティや品質担保を開発プロセスに組み込んできたご経験 | 信頼性が求められるプロダクト開発を支えてきた |
| AI活用 | AIコーディング/LLM活用を開発プロセスに取り入れてきたご経験 | AI活用を個人技ではなくチームの型にしようとしてきた |
| レガシー改善 | 技術負債や既存プロダクトの改善を推進してきたご経験 | 既存プロダクトの品質と開発速度を両立してきた |

## 6. 送る前に揃えるもの

```markdown
- [ ] 先頭行が§3のタイトルになっている（件名欄は空でよい）
- [ ] 氏名・媒体名
- [ ] 経歴・コメントから具体1〜2点（テンプレの（　）をすべて埋める）
- [ ] 山田の日程調整URL
- [ ] 募集URL（Notion JD or 採用ハブ）
- [ ] 1,000字以内（媒体カウンタ。超えたら会社説明を短縮）
- [ ] 本文に Markdown太字（`**`）や色指定を入れていない
```

**初回では書かない**: 確定年収、入社日、オファー。

## 7. 送付前チェック

- [ ] 「なぜあなた」が具体で書けている
- [ ] テックリードの役割（AI駆動開発の土台・品質・セキュリティ・運用定着）が一文で伝わる
- [ ] 医療領域の社会意義と、技術品質/セキュリティの重要性が伝わる
- [ ] 他社・現職へのネガティブ表現なし
- [ ] タイトルは1行目のみ（挨拶の前）。タイトル行を本文中に繰り返していない
- [ ] 太字・色・HTMLなし（`**` が残っていない）
- [ ] URLは単独行で貼り、クリックできる
- [ ] リンク・日程URLが有効
- [ ] 1,000字以内（タイトル・URL・改行込み）
