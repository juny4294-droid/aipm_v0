# 要件: 逆紹介候補先の一覧をまとめて印刷したい

> 出典: [Notion バックログ](https://app.notion.com/p/35a1da5a7f3b80d2a925e8454f4c71bf)（2026-05-07 / ステータス: 仮説検証）  
> 同期日: 2026-07-14

## 1. 背景（Why）

複数テナントから同種の要望。

| テナント | 背景 |
|---------|------|
| 新東京病院（連携室・全員） | 1人の医師が半日に40〜60人。無駄な印刷フローを減らしたい。「メディグル検索のように複数医療機関をまとめて印刷したい」 |
| がん研有明病院（連携室） | 窓口/診察室では1院に絞れず、複数候補を患者に渡して持ち帰ってもらう。現状は単票を複数枚出す工数が重い。糖尿病など診療圏が広いケースで希望度が高い |

**共通課題**: 選んだ複数の医療機関を、患者に渡せる形で1枚（または1束）にまとめて印刷できる導線がない。

## 2. 要求（What）

連携マップ上で複数の逆紹介候補先を選択し、患者に渡せる一覧（地図・詳細情報付き）としてまとめて印刷できる状態にする。

## 3. 要件・要確認（Howの制約）

- 対象: foro 連携マップ
- 最大何件程度のリストを渡すか（要確認）
- 一覧ページ印刷か、個別ページをまとめて印刷か
- 一覧の場合の情報項目の優先順位（住所 / 地図 / 診療科 / 連絡先等）
- **どのページからどう選択させるか**（リスト / 地図 / 両方）
- 既存の単票印刷（患者案内）との使い分け・併存

### Notion追記（追加検討）

- 一覧ページは個別を省略した内容で **1ページ4件程度** のイメージ
- → 一括（個別ページ束）より **印刷枚数が少なくなる**
- 軽くワイヤーを作ってヒアリングする

## 4. スコープ外（Not）

- SMSで候補リストを送る機能（別チケット）
- 検索一覧画面の情報項目見直し（逆紹介数の表示削除等）（別チケット）
  - 印刷用一覧は **別画面想定**

## 6. 現状の代替手段 / 既存UI

- 代替: 候補先ごとに詳細 →「患者案内」で単票印刷を繰り返す
- 既存: 検索結果（リスト / 地図タブ）→ 医療機関詳細 → 患者案内（単票）/ 患者案内（詳細版）
