# foro入退院 現行画面（モックの土台）

> 写した日: 2026-10-14
> 正本: `medup-core-service` の `origin/develop`（2026-09-17、`feat/acf-web-patient-form` まで）
> 動く土台: [current.html](current.html)
> 更新するときのファイル一覧: [sources.md](sources.md)

相談の受付から入院・退院の確定までを追う画面。左のナビは「相談一覧」と「ダッシュボード」。画面の正式名は「foro 入退院調整」。

この文書は、相談一覧の作り直し（ステータスのタブ、全項目の相談フォーム）が入ったあとの画面である。フラグ `NEXT_PUBLIC_FEATURE_FLAG_TRANSFER_REQUESTS_REDESIGN` が有効なときの見た目に合わせている。追加開発のモックでは、頼まれたところだけを足し、ここに書いた動きは残す。

## 相談一覧

パスは `/transfer-requests`。見出しは「相談一覧」。

上にタブがある。件数は、そのタブに属するステータスの合計。

| タブ | 中のステータス |
|---|---|
| すべて | 全ステータス |
| 進行中 | 新規受付 |
| 判断・対応待ち | 判定待ち、受入可、日程調整中、ベッド待機中、退院先調整中 |
| 確定・完了 | 入院確定、退院確定 |
| 終了・対象外 | 受入不可、相談取下げ |

タブの下の左に検索、ステータスの絞り込み、連絡待ちの絞り込み、「ステータスについて」。右に「相談の新規登録」と、その横のメニュー。

検索の対象は、管理番号、患者ID、氏名、疾患、紹介元医療機関。ステータスの絞り込みに出るのは、開いているタブのステータスだけ。

「ステータスについて」は説明のモーダルを開く。

メニューの中身は次の3つ。

- CSVダウンロード
- 紹介元医療機関の設定
- 疾患の設定

一覧の列は次のとおり。行にカーソルを乗せると、患者のサマリーカードが出る。

| 列 | 備考 |
|---|---|
| 管理番号 | ソートできる |
| 氏名 | 見出しの目のアイコンで、表示と伏字を切り替える。初期は伏字 |
| 年齢 | |
| 性別 | 男性 / 女性 |
| 疾患 | |
| ステータス | 下の10種。色付きのバッジ |
| 紹介状受領日 | ソートできる |
| 紹介元医療機関名 | 正式名があれば正式名 |
| 連絡待ち | 理由がなければ「-」 |
| 更新日時 | 近いときは「n分前」「n時間前」「1日前」。それより前は日付 |
| 添付 | ファイルがある行だけクリップの印 |
| 操作 | 行を開くと編集のサイドピーク |

サマリーカードに出るのは、氏名、年齢、性別、ステータス、管理番号、疾患、紹介元、退院ステータスとその日付、連絡待ち、最終更新日時、特記・注意。

### ステータス

| 画面の文言 | バッジの色 | 説明 |
|---|---|---|
| 新規受付 | 青 | 相談を受け付け、内容をまだ確認していない |
| 判定待ち | 黄 | 入院受入の可否を院内で確認している |
| 受入可 | 青 | 入院の受入が可能と判断された |
| 日程調整中 | 青 | 患者・家族や関係者と入院日を調整している |
| ベッド待機中 | 黄 | 受入可能だが、病床の確保を待っている |
| 退院先調整中 | 黄 | 自宅・施設・転院先など、退院後の行き先を調整している |
| 入院確定 | 緑 | 入院日と受入予定が確定した |
| 退院確定 | 緑 | 退院が確定した |
| 受入不可 | 灰 | 今回は受入できないと判断された |
| 相談取下げ | 灰 | 患者・家族または紹介元の意向により相談を終了した |

### 連絡待ちの理由

病状安定待ち、入院検討中、面談日調整中。チェックを付けたときだけ理由を選ぶ。外すと理由は消える。

### 相談の編集（サイドピーク）

見出しは「相談の編集」。幅は 704px。管理番号は表示のみ。下にステータス履歴がある。

冒頭はステータス（タブと同じ4グループでまとめる）、連絡待ち、入院確定のときだけ入院確定日。

| セクション | 項目 |
|---|---|
| 基本情報 | 相談受付日、受付ID、担当者名、入院日、病棟名、主治医名、受入可否（可 / 不可 / 検討中）、患者ID、紹介状受領日 |
| 1. 紹介情報 | 紹介元医療機関、紹介元担当者、入院・紹介目的、選択理由 |
| 2. 患者情報 | 氏名（カナ）、氏名（漢字、必須）、生年月日、年齢（必須）、性別（男 / 女、必須）、住所、主病名（必須）。要配慮情報の権限があるときだけ、診断名（補足）、発症日、疾患カテゴリー、既往歴、かかりつけ医、アレルギー（食物・薬剤） |
| 3. 経過報告・医療状況 | 権限があるときだけ。経過報告、医療状況、麻痺、コミュニケーション、嚥下、認知症、夜間の状態、精神面・情緒、意欲・参加意識、夜間・精神面の補足 |
| 4. ADL | 権限があるときだけ。起居・移乗、立位・座位保持、移動方法、排便、排尿、食事摂取、更衣・整容、入浴。それぞれ発症前と現在（自立 / 見守り / 一部介助 / 全介助）。食事形態、排泄方法 |
| 5. 発症前の生活・社会背景 | 権限があるときだけ。発症前の生活、排泄方法（発症前）、利用していたサービス、家族構成・同居者、キーパーソン |
| 6. 介護・保険情報 | 権限があるときだけ。介護認定、入院時連携シート（有 / 無）、ケアマネ、居宅介護支援事業所 |
| 7. 本人・家族の意向／希望 | 希望部屋（権限があるとき）、入院希望日、家族面談、希望日との誤差（入院希望日と入院日から表示） |
| 8. 院内確認・決裁 | 受領書類、医師確認、Dr名（1人目）とその可否、Dr名（2人目）とその可否、業務チェック、送迎手段 |
| 9. 特記事項 | 特記事項 |
| 10. ソーシャル情報 | 権限があるときだけ。本人の意向、家族の意向、ソーシャル情報 |
| 転帰先 | 自宅 / 施設 / 転院 / その他 |

土台のモックは、要配慮情報の権限があるユーザーとして全セクションを出している。

新規はモーダル「相談の新規登録」で、同じ項目を空から入れる。管理番号は登録時に採番する。

## 見た目

画面の地は `#FBF8FF`。ヘッダーは塗らないので、この地がそのまま見える。左ナビと相談一覧の紙面は白。フォントは Helvetica Neue、Arial、ヒラギノ角ゴ、ヒラギノ、メイリオ。

## ダッシュボード

パスは `/dashboard`。見出しは「ダッシュボード」。地色の上に、白い角丸のパネルが乗る。

- 進行中の相談案件。新規受付、判定待ち、受入可、日程調整中、ベッド待機中。件数は右寄せで、前日比はグレー
- 相談実績。初期の月は前月。入院確定、受入不可、相談取下げ。件数も見出しもグレーで、前月比付き
- 疾患別入院実績。紹介元医療機関で絞れる。新規受付（青）と入院確定（緑）の縦棒、入院確定率
- 紹介元医療機関別入院実績。同じ3系列の横棒

## ヘッダー

見出しの右にアカウント。開くと、名前、個人設定、ユーザー管理（owner のみ）、ログアウト。

## モックで簡略しているところ

- 添付ファイルは有無の印まで
- ダッシュボードのグラフは静的な棒。入院確定率の折れ線は凡例だけ。月の選択と紹介元の絞り込みは見た目だけ。退院先調整中と退院確定のカードは、本番の集計にはまだ入っていない
- 紹介元医療機関の設定は一覧まで。正式名の編集と並び替えは本番にある
- 個人設定とユーザー管理の中身は含めていない
- データは架空。保存はブラウザの中だけ
