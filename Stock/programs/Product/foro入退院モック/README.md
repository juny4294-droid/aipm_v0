# foro入退院のモック

仕様と、このフォルダのパスを指定して、モックを作ります。仕様はリンクでも、本文を貼っても構いません。

## 頼み方

次の3行を、そのままエージェントに渡します。フォルダと仕様は、両方書きます。

```
AGENTS.md に従って、この仕様をもとに入退院のモックを作って。
フォルダ: /Users/sample/Desktop/foro入退院モック
仕様: https://www.notion.so/example の VoC No.3
```

仕様のページの一部だけ作るときは、上のように「の VoC No.3」と範囲を書きます。フォルダは開いていなくても、パスが書いてあれば足ります。パスとリンクは、渡す人のものを書きます。

リンクを貼らず、仕様の本文を渡すときは、仕様の行から続けて書きます。

```
AGENTS.md に従って、この仕様をもとに入退院のモックを作って。
フォルダ: /Users/sample/Desktop/foro入退院モック
仕様:
一覧に希望入院日の列を足したい。
```

できたモックは、このフォルダの隣の `モック/<短い名前>/` に出ます。中身は `mock.html` と `参照.md` です。`mock.html` をブラウザで開いて、押して確認します。`参照.md` には、どの仕様から作ったかだけを残します。仕様の写しは作りません。

仕様を直したあとは、同じ会話で「仕様を更新したので、モックも合わせて」と続けます。
