# アウトプットファイル仕様

コーディング結果を、ユーザーが扱いやすい Excel（VBA）に加工する。入力は2つ。

| 入力 | 内容 |
|---|---|
| 患者一覧 | Excel。取り込み後に「患者一覧」シートになる |
| コーディング結果 | CSV（Excel も可）。取り込み後に「コーディング結果」シートになる |

## 1. ブックのシート

最初からあるシートは「表紙」「結果」「点数表」。患者一覧とコーディング結果は、取り込みのときにシートとして追加される。同じ名前のシートがすでにある場合は、中身を入れ替える。

「点数表」シートは診断群分類電子点数表（有効期間 2026-06-01〜）をそのまま入れたもの。マスタは変わらない前提で、ブックに最初から組み込んでおく。

コーディング結果シートは、根拠の文章などセル内に改行を含む列があり行が縦に長くなるため、データ行の高さを90ピクセル（67.5pt）にそろえ、縦位置を上揃えにする。また先頭行（見出し）を固定する。

結果シートを更新するたびに、コーディング結果シートは結果シートで使った行だけを表示し、それ以外の行を非表示にする。表示するのは、「コーディング結果（最高自信度）」に使った行（患者IDのリンク先）と、「コーディング結果（閾値）」に使った行。行は消さないので、行の再表示で全件見られる。閾値を変えて更新すると、表示する行も選び直す。結果シートに出ない患者（患者一覧にない患者）の行は非表示になる。コーディング結果を取り込み直すと、いったん全行を表示に戻す。

### 表紙

ボタンは3つ。

1. **患者一覧を取り込む** … ファイルを指定し、「患者一覧」シートとして取り込む。点数が空の行は「点数表」から計算して入れる（6章）
2. **コーディング結果を取り込む** … ファイルを指定し、「コーディング結果」シートとして取り込む
3. **結果シートを更新** … 取り込んだ2シートから「結果」シートを書き直す

B15 は「自信度の閾値」。0.5〜1 を 0.1 刻みのプルダウンで選ぶ（初期値 0.5）。結果シートを更新するたびにこの値を読む。空や範囲外の値のときは更新を止める。

開くときはマクロを有効にする。ブックを開くと表紙が表示される（Auto_Open で表紙を選ぶ。保存も表紙を選んだ状態で行う）。

### 結果

表紙の「結果シートを更新」で書き込まれる。患者IDと入院日が、患者一覧とコーディング結果の両方にある行だけを出す。

## 2. 患者一覧に必要な列

| 使う列 | 見出しとして受け付ける名前 |
|---|---|
| 患者ID | 患者ID、患者番号 |
| 入院日 | 入院日、入院年月日 |
| 退院日 | 退院日、退院年月日 |
| 現状のDPC | DPCコード14桁、DCPコード14桁、DPCコード |
| 現状の点数 | 点数（空の行は取り込み時に計算する。列がなければ取り込み時に「点数」列を作る。6章） |
| 診療科 | 診療科（なくてもよい。ないときは結果の見出しだけ出す） |
| 病棟 | 病棟（なくてもよい。ないときは結果の見出しだけ出す） |

患者ID、入院日、退院日、DPCコード14桁、点数の列がない場合は更新を止める。退院日は列があれば、値が空の行も結果に出す。その行の退院日と在院日数は空にする。

## 3. コーディング結果から使う列

| 列 | 用途 |
|---|---|
| patient_id | 患者一覧の患者IDと突き合わせる |
| admission_date | 患者一覧の入院日と突き合わせる |
| dpc14 | AIコーディングのDPC |
| final_total_score | AIコーディングの点数 |
| step1_confidence | 自信度。最も高い行を採用する |
| final_decision | 自信度が同点のとき、`selected` の行を優先する |
| step1_icd10 | AIコーディングのICD10コード（なくてもよい。ないときは空） |
| step1_icd10_name | AIコーディングのICD10名称（なくてもよい。ないときは空） |

同じ患者・同じ入院に候補が複数あるときは、`step1_confidence` が最大の行を使う。その最大値が複数行で同じときは `final_decision` が `selected` の行を優先し、それでも分かれるときは点数が高い行を使う。

## 4. 結果シートの列

見出しは2行。1行目は列のまとまり、2行目は各列の名前。データは3行目から。

| 1行目 | 2行目 | 内容 |
|---|---|---|
| AIコーディング前 | 患者ID | 患者一覧。クリックすると「コーディング結果」シートの、採用した候補の行へ移動する |
| | 入院日 | 患者一覧 |
| | 退院日 | 患者一覧 |
| | 在院日数 | 退院日 − 入院日 + 1。退院日が空のときは空 |
| | 診療科 | 患者一覧。列がなければ空 |
| | 病棟 | 患者一覧。列がなければ空 |
| | DPC | 患者一覧の DPCコード14桁 |
| | 点数 | 患者一覧の点数 |
| コーディング結果（最高自信度） | ICD10コード | 自信度が最も高い候補の step1_icd10 |
| | ICD10名称 | その候補の step1_icd10_name |
| | DPC | 自信度が最も高い候補の dpc14 |
| | 点数 | その候補の final_total_score |
| | 点数差 | その点数 − 一覧の点数 |
| | コード一致 | 下の比較 |
| | 評価 | 下の判定 |
| コーディング結果（閾値{閾値}以上） | 最高点のDPC | 下の「閾値以上の最高点との比較」で選んだ候補の dpc14 |
| | 点数 | その候補の final_total_score |
| | 点数差 | その点数 − 一覧の点数 |
| | 増収候補 | その点数が一覧の点数より高ければ「増収候補」、高くなければ「対象外」、どちらかが数値でなければ空 |

1行目の {閾値} には、更新したときの表紙の閾値が入る（例：コーディング結果（閾値0.7以上））。1行目はまとまりごとに「選択範囲内で中央」で表示し、セル結合はしない。

見出しは色で2つに分ける。AIコーディング前（患者ID〜点数）は青、それ以降（ICD10コード〜増収候補）は緑にする。まとまりの境目には白い縦線を入れる。オートフィルターは2行目に付け、見出し2行を固定する。

### 閾値以上の最高点との比較

増収候補を多く拾うための比較。同じ患者・同じ入院の候補のうち、`step1_confidence` が表紙の閾値以上で、dpc14 と点数があるものから `final_total_score` が最も高い行を選ぶ。点数が同じなら自信度が高い行を選ぶ。該当する候補がなければ4列とも空にする。

### コード一致

現状のDPCと、AIコーディングのDPC（14桁）を比べる。空白と大文字小文字の違いは無視する。

| 条件 | セルの値 |
|---|---|
| 14桁が完全に一致 | 完全一致 |
| 1〜6桁目が一致し、7〜14桁目が不一致 | 7桁以降不一致 |
| 1〜6桁目が不一致、またはどちらかが空 | 6桁不一致 |

### 評価

コード一致の結果と、一覧側の点数・AIコーディングの点数から決める。

| コード一致 | 点数 | セルの値 |
|---|---|---|
| 完全一致 | 問わない | 一致 |
| 7桁以降不一致 | 問わない | 要確認 |
| 6桁不一致 | AIコーディングの点数の方が高い | 増収候補 |
| 6桁不一致 | AIコーディングの点数の方が低い | アップコーディング候補 |
| 6桁不一致 | 同じ | 一致 |
| 6桁不一致 | どちらかが空、または数値でない | 要確認 |

## 5. 突き合わせ

結合キーは患者IDと入院日。患者番号は数値として揃える。日付は `yyyy-mm-dd` に揃える。コーディング結果に対応する行がない患者は、結果シートに出さない。

## 6. 患者一覧の点数の計算

患者一覧の取り込み時に行う。一覧に点数が入っている行はその値を使い、空の行だけを「点数表」から計算して、患者一覧シートの「点数」に書き込む。列は増やさない。取り込み完了のメッセージに、一覧の値・計算した件数・計算できなかった件数を出す。

### 点数表の引き方

患者一覧の DPCコード14桁で「診断群分類番号」の行を引く。空白と大文字小文字の違いは無視する。使う列は「入院日（日）」のⅠ〜Ⅲと「点数（点）」の入院期間Ⅰ〜Ⅲ。

### 計算用の在院日数

| 退院日 | 計算用の在院日数 |
|---|---|
| あり | 退院日 − 入院日 + 1（結果シートの在院日数と同じ） |
| 空 | 点数表の入院日Ⅱ（入院期間Ⅱの最後の日まで入院したとみなす） |

結果シートの「在院日数」は、退院日が空なら空のまま。計算用の日数は点数の計算にだけ使う。

### 点数

入院日Ⅰまでの日は1日あたり入院期間Ⅰの点数、入院日Ⅰの翌日から入院日Ⅱまでは入院期間Ⅱの点数、入院日Ⅱの翌日から入院日Ⅲまでは入院期間Ⅲの点数で、日ごとに足し上げる。

例：010010xx9901xx（入院日Ⅰ=6、Ⅱ=18、Ⅲ=60、点数Ⅰ=3556、Ⅱ=2559、Ⅲ=2175）で在院10日の場合、6日 × 3556 + 4日 × 2559 = 31,572点。退院日が空なら18日として 6 × 3556 + 12 × 2559 = 52,044点。

計算用の在院日数が入院日Ⅲを超える場合は、入院日Ⅲまでの合計を点数にする（超えた日は出来高のため足さない）。

入院日Ⅰ＝入院日Ⅱの行（点数Ⅱが「-」）は入院期間Ⅱがなく、入院日Ⅰの翌日から入院期間Ⅲになる。

### 点数を入れない（空のまま）場合

| 条件 | 理由 |
|---|---|
| DPCコードが空 | 引けない |
| DPCコードが点数表にない | 引けない |
| 点数表の入院日・点数が未記入 | 出来高評価の対象 |
| 入院日が日付でない、または退院日が入院日より前 | 日数を出せない |
