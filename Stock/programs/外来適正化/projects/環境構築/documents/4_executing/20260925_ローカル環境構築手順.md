## 1. リポジトリを用意する

スクリプトの置き場は [MedUpInc/outpatient-ops](https://github.com/MedUpInc/outpatient-ops)。クローンし、開発環境を整えて使う。

```bash
git clone https://github.com/MedUpInc/outpatient-ops.git
cd outpatient-ops
```

## 3. 済生会（テナント 11）で動くことを確認する

設定は診療科ごとの yaml に、実行ファイル名と日付（開始・終了）を書く。例は `src/pipeline/tenants/t011/respiratory_surgery.yaml`。

実行は `uv run` でモジュールを指定する。ページに残っている実行例は次のとおり。

```bash
uv run python -m src.pipeline.tenants.t011.urology
uv run python -m src.pipeline.tenants.t011.respiratory_surgery
```

ページ上の実行結果（2026-09-25）では、出力先は `outputs/11/2026-09-25/` 配下の Excel。

## 4. ドクターマスターを参照できないとき

参照権限がない場合は、snapshot を見るように変える。対象は `src/bigquery/models/dpc.py` の 143 行目。

```python
__tablename__ = "sk-kumamoto_doctor_master"
```

これを次に変える。

```python
__tablename__ = "sk-kumamoto_doctor_master-snapshot"
```

済生会熊本向けの差し替えとして書かれている。
