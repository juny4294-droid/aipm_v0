# 外来適正化

外来適正化サービスのプログラム（プロダクト）ディレクトリ。

実行月を M とすると、臨床データは M-1 月の末日まで、予約は M+1 月分。2026-10 に実行するなら、臨床データは 2026-09-30 まで、予約は 202611。その病院の分が欠けていれば、その病院は抽出しない。手順は病院ごと。

## 済生会熊本（tenant 11）

泌尿器科・呼吸器外科。`~/ws/outpatient-ops` で実行する。

- 前月までの外来EF
- 来月の外来予約CSV（両科）
- 来月の手術予約CSV（泌尿器科のみ）

手順: `projects/環境構築/documents/4_executing/20260925_次回抽出手順.md`

## 新東京（tenant 135）

心臓内科・糖尿病内科。`~/ws/outpatient-ops` で実行する。受領データは [Drive](https://drive.google.com/drive/u/0/folders/1PuAtQQQqT1ivaPKaqvAD4Dg9EnBB1ZiP)。

- 前月までの外来EF
- 来月の予約xlsx（各科。外来予約・手術・内視鏡のシート）

郵便番号と外勤先リストは月次の受領データではない。手元の固定ファイルを使う。糖尿病内科は、在宅自己注射指導管理料の算定患者をデフォルトで除外する。

手順: `projects/環境構築/documents/4_executing/新東京_月次抽出手順.md`

## 鳥取県立中央（tenant 274）

月次で抽出を実行するのは脳神経外科。整形・泌尿も、受領と投入の確認先は同じ。BigQuery に SQL を直接実行する。入院EFは使わない。来月の通院予約は、候補を出したあとに患者IDと突合する。

手順: `projects/鳥取県立中央データ抽出/documents/4_executing/脳神経外科_月次抽出手順.md`
