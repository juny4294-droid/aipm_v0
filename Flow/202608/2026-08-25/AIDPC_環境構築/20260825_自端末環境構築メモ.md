## 手順（公式 README / SETUP 準拠）

### A. ツール導入

```bash
# Python 3.12（uv が管理してもよい）
brew install uv just
# Docker Desktop は公式インストーラ or brew --cask docker
```

### B. リポジトリ

```bash
cd ~/ws
git clone https://github.com/MedUpInc/ai-dpc-multi-agent.git
cd ai-dpc-multi-agent
```

### C. 依存関係・env

```bash
cp .env.example .env
# UV_INDEX_URL を Takumi Guard のトークン付き URL に置換

cp apps/dpc-coding-core/.env.example apps/dpc-coding-core/.env
# V2_DATABASE_URL / OPENAI_API_KEY または AWS_*（Bedrock）を設定

uv sync --dev
```

### D. DB + マスタ（現行は SQL dump ではなく Parquet bundle）

```bash
just emu-up
just core::migrate-up

# local backend（emulator seed 不要）
# apps/dpc-coding-core/.env:
#   V2_MASTER_BACKEND=local
#   V2_MASTER_LOCAL_ROOT=/Users/junyamada/ws/aidpc-master-bundle

MASTER_LOCAL_TEST_ROOT=/Users/junyamada/ws/aidpc-master-bundle \
MASTER_LOCAL_TEST_SCHEMA_VERSION=v1.1 \
just core::test-integration-local
```

emulator 経由にする場合だけ:

```bash
just core::master-seed /Users/junyamada/ws/aidpc-master-bundle
just core::master-verify
```

### E. 実行（患者データ投入後）

`core::` recipe の CSV パスは **app 相対**。

```bash
just core::run 11 patients/std/cases.csv
# または
just core::run-openai 11 patients/std/cases.csv
```
