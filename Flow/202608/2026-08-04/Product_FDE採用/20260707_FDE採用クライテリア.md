# 1. 人材像

- CS/PSと**一緒に病院現場**に入り、業務課題を整理し、**設計 → 実装 → 効果確認 → 改善**まで自分でやり切れる人。
- **1人目FDE**として、組織づくり・組織のマインドづくりを推進できる人。

### FDEに求めるもの

**役割**

| 区分 | 内容 |
|------|------|
| Must | 自らユーザーとコミュニケーションをとり、その病院の理想の業務フローと現状のギャップの洗い出しが行える。 |
| Must | 実運用を前提にした業務設計、投入データ設計ができる（業務フロー＋データフロー） |
| Must | 実装から検証、改善まで自走できる |
| Nice to Have | 0ベースから事業を企画し立ち上げを行える |
| Nice to Have | 安定運用まで責任を持って改善できる |

**マインドセット**

| 区分 | 内容 |
|------|------|
| Must | 不確実性の高い環境でも、自律的に考え前に進められる |
| Must | 医療ドメインへの関心と、現場と衝突するとしても、病院経営上のあるべき姿を提示しより良い解決策を作り上げる姿勢 |
| Must | 個人の成果だけでなく、チーム・組織への良い影響を意識できる |

**スキル**

| 区分 | 内容 |
|------|------|
| Must | 業務課題を構造化し、論点・仮説・打ち手を整理できる |
| Must | 技術制約を理解し、設計・実装できる |
| Nice to Have | 関係者を巻き込み、優先度・スコープ・進め方を設計できる |
| Nice to Have | 医療データや病院システムへの知見がある |
| Nice to Have | AIを活用して、短いサイクルで実装・改善を進められる |
