## 1. 整形外科（先に着手候補）

### 対象
- 併科 **含む**
- 最大行為が **処置/手術/注射以下**（点数線引きなし・受診回数で一律除外しない）
- 骨粗鬆症注射（プラリア等）は回数が多くても対象

### 除外
| 条件 | 実装メモ | 状態 |
|------|----------|------|
| CT・MRI | outpatient_ef のレセプトコード。CTコード一覧は作業メモにあり。**MRIコードは「あとで」** | 🟡 MRIコード未完 |
| ギプス・脱臼 | ギプス or 非観血的整復術。**どちらで除外するか CS確認待ち** | 🔴 要確認 |
| 逆紹介済み | public_reverse_referrals | ✅ |

### クエリ化の骨格（作業メモより）
1. 親集合から整形外科医師担当の患者
2. 最大行為フィルタ
3. CT/MRI算定 patient_id を除外
4. ギプス・脱臼算定 patient_id を除外
5. 逆紹介済みを除外

## 2. 脳神経外科（難所）

### 対象
- **単純MRIフォロー**（1.5T / 3.0T 算定）
- ※病名ベースの「良性腫瘍・頭部外傷・脳卒中後・くも膜下6年以上」は病名特定が難しいため、**まずはMRI算定＋除外で寄せる**方向

### 除外と実現性

| 条件 | 実現性メモ | 状態 |
|------|------------|------|
| 併科 | 可 | ✅ |
| CT算定あり | 可 | ✅ |
| 悪性腫瘍 | DPC `010010 脳腫瘍`／入院手術／悪性腫瘍管理料？ 病名特定は不可寄り | 🟡 |
| 血管内手術後 | 手技指定が必要。血小板凝集能は代理指標。6年以内手術は可 | 🔴 手技コード要指定 |
| 造影MRI継続 | **直近MRIに造影剤使用加算あり** → OK（黒川確認済・約250点） | ✅ 方針確定 |
| てんかん | てんかん指導料でOK | ✅ |
| くも膜下術後6年未満 | DPC `010020` | 🟡 |
| 逆紹介済み | 可 | ✅ |

### 顧客確認事項（クエリ外だが関連）
- 3.0T撮影中患者をおおたけ（1.5T）に出してよいか

## 3. 泌尿器科

### 対象
- CT年2回以下
- 検査年5回以下（メインはPSA年1〜2）
- 投薬・再診のみ
- ⚠ **各条件は AND？ OR？ → 未決**

### 除外

| 条件 | 実現性メモ | 状態 |
|------|------------|------|
| 併科 | 可 | ✅ |
| MRI実施 | 可（≒前立腺がん代理） | ✅ |
| 鳥取大学からの紹介 | 紹介元で可／ロボット術後フォロー特定は不可 | ✅（紹介元で除外） |
| 前立腺がん術後5年未満 | DPC `110080`、2019/4以降データで可 | ✅ |
| 積極的監視療法 | 入院有・手術無＋定期検査。**回数・検査種の具体化が必要** | 🔴 |
| 逆紹介済み | 可 | ✅ |

## 今日の進め方（提案）

社内合意どおり **整形から先にクエリ化**するのが最短。

1. **整形**: MRIレセプトコードを埋める／ギプス除外のコード方針を決める（or CSに1問投げる）
2. 整形の除外集合クエリを書いてボリューム確認
3. 余力で脳外の造影判定サンプル確認、or 泌尿の AND/OR を決める

## 未決・要確認リスト（優先順）

- [ ] 【整形】MRI除外のレセプトコード一覧
- [ ] 【整形】ギプス除外：ギプスコード / 非観血的整復術のどちら（or 両方）？ → CS確認
- [ ] 【泌尿】CT≤2 / 検査≤5 / 投薬再診のみ の結合論理（AND/OR）

- [ ] 【脳外】血管内手術の手技コード指定
